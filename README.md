#  SQL Study: Sistema de Biblioteca (Oracle)

Este repositório contém as resoluções da **Prática 2** da disciplina de Banco de Dados na **Fatec**. O projeto foca na manipulação de dados de um sistema de biblioteca, explorando desde consultas simples até junções complexas e subqueries no ambiente **Oracle Database**.

---

##  Tecnologias e Ferramentas
* **Banco de Dados:** Oracle SQL
* **Linguagem:** SQL (Sintaxe ANSI e Oracle Tradicional)

---

##  Tópicos Praticados

Nesta prática, foram desenvolvidos scripts para:

* **Joins Complexos:** Conexão entre múltiplas tabelas (Pessoa -> Emprestimo -> Item -> Livro).
* **Outer Joins:** Listagem de dados mesmo na ausência de registros relacionados (usando `LEFT JOIN` e o operador `(+)` do Oracle).
* **Funções de Agregação:** Uso de `COUNT`, `SUM`, `MIN` e `MAX` para estatísticas de uso.
* **Agrupamentos:** Aplicação de `GROUP BY` e filtragem de resultados agregados com `HAVING`.
* **Ordenação e Limites:** Uso de `ORDER BY` e `FETCH FIRST` para rankings de usuários e livros.
